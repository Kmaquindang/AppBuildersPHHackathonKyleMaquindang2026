- Oct 9, 6:24 PM: Encrypted rooms (commits 310ac08, 8131273). Each room has a spoken label (not secret) and a random 256-bit key shared by QR code (CoreImage) or a join string (`PASA1.<label>.<creator>.<key>`). Protocol v2: a clear routing header (version, id, room tag, origin, destination, ttl, hops) and a ChaCha20-Poly1305 sealed payload (CryptoKit); the room tag and sealing key come from HKDF-SHA256 of the room key, and the header is bound as associated data so relays can change only ttl and hops.
